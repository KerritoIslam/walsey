# Repeatable speech-recognition test set: one utterance per line.
#
# These lines are the *expected* sentences. tools/voice_accuracy/make_tts_corpus.ps1
# speaks each line with the installed Windows text-to-speech voices and writes
# 16 kHz mono PCM16 WAV files next to a manifest; bin/voice_accuracy.dart then
# compares the raw Vosk/Whisper transcript with these exact strings.
#
# Two kinds of line:
#
#   turn the lights on      a command: the transcript must parse to this intent
#                           and these parameters.
#   !play some music        a negative written with a leading "!": the utterance
#                           must NOT become a command. A transcript that parses
#                           is reported as a FALSE COMMAND, which is a safety
#                           failure rather than an accuracy miss.
#
# This is synthetic speech, not human recordings: useful for a deterministic,
# repeatable regression baseline, not a substitute for the on-device checklist.
# The original 30 lines are kept first and unchanged so file names stay stable
# and old baselines stay comparable; new lines are appended.
#
# Keep the vocabulary inside what the Stage 1 parser accepts.
