## Color
| Token | Hex | Use |
|---|---|---|
| bg | #0E0F14 | App background |
| surface | #171923 | Cards, panels |
| surfaceRaised | #1F2230 | Sheets |
| border | #262A38 | Card/row borders |
| text / textSecondary / textMuted | #E8EAF2 / #B4BACB / #9AA1B5 | Text |
| primary | #7B6CF6 | Primary buttons, toggles, progress |
| primaryTint / primaryText | #242246 / #B7AEFF | Active nav, concept badges |
| accentCyan | #3DD6E8 | Audio levels, secondary accent |
| success | #4CC38A (bg #12362A, text #6FE0A8) | Online, done |
| warning | #F2B04A (bg #3A2C10, text #F5C26B) | Connecting |
| error | #E5646B (bg #3A1A1E, text #F59BA0) | Failed, unavailable |

Status badges always use label + color (never color alone): Online, Connecting, Offline (grey), Unavailable (error), Concept (violet).
